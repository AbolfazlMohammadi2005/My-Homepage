C Odyssey

About This Project

CODYSSEY – A structured coding journey through the world of C from basics to advanced concepts. This repository contains code examples, exercises, and small educational projects for learning C step by step. Each chapter focuses on a specific topic, and the code is provided with explanatory comments.

📂 Repository Structure :

01 - Fundamentals (variables, data types, operators, I/O with printf and scanf)
02 - Conditional Statements (if, else if, switch, ternary operator)
03 - Loops (for, while, do-while, nested loops)
04 - Random Number (rand, srand and random distributions)
05 - Function (definition, prototypes, parameters, return values)
06 - Template (generic code in C: macros, void pointers)
07 - Cmath (math.h: sqrt, pow, sin, cos, etc.)
08 - Array (1D, 2D, character arrays)
09 - STL (container-style data structures and algorithms built by hand in C)
10 - String (C strings, character arrays, string.h functions)
11 - File (reading/writing text and binary files with stdio.h)
12 - Pointer (pointers, pointer arithmetic, dynamic memory with malloc and free)
13 - UDT (struct, enum, union, typedef)
14 - Time (time.h)

⚙️ Prerequisites: C11 or higher compiler (GCC, Clang, MSVC), basic command-line knowledge.
