Microcontroller Odyssey

About This Project

Microcontroller Odyssey is a structured, hands-on learning project dedicated to AVR microcontroller programming in C. Using the ATmega32 as its target platform, the project progresses from fundamental digital I/O operations to peripheral interfacing and interrupt-driven programming.

This project is the third part of the Odyssey trilogy: C Odyssey → C++ Odyssey → Microcontroller Odyssey. It brings C programming concepts into embedded systems through practical, chapter-by-chapter programs developed for CodeVisionAVR, with Proteus simulation or real hardware used for testing.

Each chapter organizes the relevant programming concepts and microcontroller features into practical examples and exercises, helping learners connect the fundamentals of C with real embedded applications.

📂 Repository Structure

01 - Digital Output
02 - Shift Operations, Arrays & 7-Segment Displays
03 - Loops & Strings
04 - Functions & Multi-File Projects
05 - Storage Classes & Static Variables
06 - Pointers & LCD Interfacing
07 - Enumerations & Finite State Machines
08 - Structures, Unions & Bit-Fields
09 - Digital Input, Debouncing & Keypads
10 - External Interrupts
11 - Timers, Counters, CTC & PWM
12 - Analog-to-Digital Conversion (ADC)
13 - USART Serial Communication

⚙️ Tools & Requirements: CodeVisionAVR, Proteus or compatible physical hardware, an ATmega32 microcontroller running at 8 MHz, and basic knowledge of the C programming language.

🎯 Learning Objectives: Understand microcontroller I/O, write modular C programs, interface displays and input devices, configure timers and interrupts, read analog signals using the ADC, and communicate through USART.
